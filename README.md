# MATLAB Simulink MCP

An MCP server for allowing LLMs to interact with MATLAB and Simulink; forked from https://github.com/jefferson-research/matlab-simulink-mcp

## Usage

```bash
uv pip install matlab-simulink-mcp
```
and then run:

```bash
matlab-simulink-mcp
```

or

Use `./cursor/mcp.json` to import the MCP server into Cursor.
